      Installation & configuration details

      Saved destinations are used by new Copilot sessions. Reachable means the API responds; it does not prove an observer is running. Existing sessions keep the configuration they started with. Environment overrides in the Copilot host may differ.

      Set up your physical ESP32 Orb below. Already connected? Your saved settings load automatically over Wi-Fi; USB is only needed for first-time setup, changing Wi-Fi, or installing the observer.

      Connect the Orb with a USB data cable, then select it here.

      Set up or change Wi-Fi
      Wi-Fi setup over USB

      Select a USB device in step 1 first. Use a 2.4 GHz network. Leave the passphrase empty only for an open network. Connecting restarts the Orb, then loads its settings.

      Your existing Wi-Fi connection is kept unless you connect to a new network.

      3. Connect Copilot

      With a USB device selected and the Orb on Wi-Fi, add it as an observer destination. The summary above shows whether events are configured for this ESP32, the dashboard, or both. Start a fresh Copilot session after installation.

      Select a USB device in step 1 to install or refresh the extension.

      Orb settings

      These settings are saved to the physical ESP32 over Wi-Fi. They do not change its network or observer destinations.

      GitHub notifications

      Sent to and stored on the Orb, never in browser storage or dashboard logs.

      Load settings to check whether the Orb has a saved PAT.

      Sound & display

      Save to Orb to enable its onboard buzzer. Zero volume mutes it; the active buzzer has a fixed loudness at nonzero volume. Browser audio permission is not needed.

      Tests the physical buzzer using saved settings, without changing Copilot sessions.

      Quiet hours

      24-hour clock (HH:MM), using the Orb's POSIX timezone (for example, UTC0). The browser preview uses this computer's clock.

      Save to Orb applies sound, display, quiet hours and GitHub settings to the device. The PAT is cleared from this form after saving and is never sent back to the browser.
